### 2. **Architecture and Design (21%)** 🏗️
   - **Enterprise Security Architecture**: Network segmentation, security zones
   - **Secure Wireless Networks**: WPA3, MDM integration
   - **Cloud Security**: SaaS, PaaS, IaaS models
   - **Secure Software Development**: SDLC, secure coding practices
   - **Virtualization & Container Security**
   - **Disaster Recovery & Business Continuity Planning**

### 3. **Implementation (25%)** 🔧
   - **Network Security Devices**: Firewalls, IDS/IPS, routers
   - **Identity & Access Management (IAM)**: MFA, SSO
   - **Secure Protocols**: HTTPS, SSH, VPN
   - **PKI Implementation**: Certificates, key management
   - **Endpoint Security Solutions**: Antivirus, anti-malware
   - **Mobile Device Management (MDM)**

### 4. **Operations and Incident Response (16%)** 🕵️‍♂️
   - **Security Monitoring Tools**: SIEM, network monitoring
   - **Incident Response Procedures**: Containment, eradication
   - **Forensic Tools**: Chain of custody, evidence collection
   - **Root Cause Analysis**: Investigating incidents and breaches

### 5. **Governance, Risk, and Compliance (14%)** 📚
   - **Compliance Frameworks**: HIPAA, PCI DSS, GDPR
   - **Risk Assessment**: Identifying threats, vulnerabilities
   - **Privacy Regulations**: GDPR, data protection laws
   - **Security Policies**: Governance, incident reporting
